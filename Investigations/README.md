# SOC Investigations

This directory contains documented security investigations completed in authorized lab and simulated SOC environments.

Each investigation is structured as a professional SOC case report and focuses on:

* Alert triage
* Evidence collection
* Log and telemetry analysis
* IOC enrichment
* Timeline reconstruction
* MITRE ATT&CK mapping
* Scope assessment
* Final verdict
* Containment and remediation recommendations
* Detection opportunities
* Lessons learned

Investigations are documented to demonstrate analytical reasoning rather than provide walkthrough answers to training platforms.

## Case Naming Convention

Cases are numbered sequentially:

```text
SOC-001
SOC-002
SOC-003
...
```

Example:

```text
SOC-001-credential-harvesting-phishing
SOC-002-brute-force-investigation
SOC-003-malicious-powershell
```

## Investigation Categories

As the portfolio develops, cases may include:

* Phishing
* Malware
* Web attacks
* Authentication attacks
* Network investigations
* SIEM investigations
* Endpoint investigations

All sensitive information, credentials, challenge answers, and unnecessary platform-specific details are sanitized before publication.
