# Detection Engineering

This directory contains detection logic developed from security investigations and lab exercises.

The objective is to move beyond identifying malicious activity and consider:

> How could this behavior be detected reliably in a SOC environment?

Detection content may include:

* Splunk SPL queries
* Sigma detection rules
* YARA rules
* Detection hypotheses
* False-positive analysis
* Tuning considerations

Each detection should explain:

1. What behavior is being detected
2. Which telemetry is required
3. Why the detection works
4. Possible legitimate activity that could trigger it
5. How the rule could be tuned

This directory will expand as I gain more hands-on experience with SIEM analysis and detection engineering.
